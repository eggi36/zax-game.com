Downloads

Playable demo (2001)

The official demo (Zax Demo.exe, about 50 MB) is no longer available from Reflexive or JoWooD. It is still mirrored on several download sites:

  • gamepressure.com
  • Softpedia
  • PC Games (German)

Minimum system requirements: Pentium II 233 MHz, 32 MB RAM. Mirrors are external sites – check the files before running them.

French patch

The official site offered a patch for a crash in mission 10 of the French version (Zax_French_Patch.zip). The file was not preserved by the Internet Archive.

Wallpapers

The wallpaper section of the official site was a Flash file that has not been preserved.
