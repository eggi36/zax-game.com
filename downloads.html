Downloads

Playable demos (2001)

Three demo versions were released in the summer of 2001. All three contain the same five levels. Each download is the original Windows installer.

  • Demo of 1 July 2001 – build 890, EXE dated 30 June 2001 (50.0 MB)
    The earliest demo, from an older stage of the engine. It is the only build with 3D positional sound via DirectSound3D and EAX.
  • Demo of 19 July 2001 – build 950, EXE dated 18 July 2001 (50.1 MB)
    An intermediate build shortly before the full version, without the positional sound of the first demo.
  • Demo of 6 August 2001 – build 1308, EXE dated 1 August 2001 (50.9 MB)
    Technically the EXE of the full version without copy protection – only its smaller data set makes it a demo.

Minimum system requirements: Pentium II 233 MHz, 32 MB RAM. File list and SHA-256 checksums: release page.

French patch

Zax_French_Patch.zip (3 KB, February 2002) – fixes the crash in mission 10 of the French version. Copy 1French.RED into the Zax folder (where Zax.exe is); save games keep working.

Community downloads

  • Zax-Launcher – a launcher for the original Zax.exe: start directly into any map with a start point and difficulty of your choice, a “Load Map” button in the game menu, and the developer switches still hidden in the exe (debug log, frame rate, cheats and more). The exe itself is not modified; full support for build 1308/1309 without copy protection.
  • Zax Editor – a level editor for Zax maps: objects, polygons, ground, surfaces, mini map, transitions and dialogue scripts, own graphics, a model viewer and a “Test in game” button. English with a German translation.

Fan-made tools, not affiliated with the rights holders. More projects around the game are listed on the Projects page.
