Steve
• Fixed bug in SentinonAI that causes Sentinon to deploy when player is within range but not visible (i.e., Sentinon apparently could see through walls but not fire through them ... now Sentinon can't see through walls either). Side effect of this fix is that Sentinon will be collideable when idle, but I really don't think this is a significant thing. If it is, someone let me know.
• Removed all the conditional compilation stuff for NO_SET_FACING_ANGLE. Once checked in, this will have a wide impact so I am going to be working to minimize that impact by getting into a lot of StarTrek code that uses SetFacingAngle(), replacing those obsolete calls with appropriate new calls.
• Added CEntityAnimatedUpperBody to handle upper body stuff, as opposed to using CEntityAnimated for upper bodies.
• Modified Crater model to use CEntityAnimatedUpperBody. More work needs to be done to restore all previous functionality. Expect some anomalies with this change, please report any errant behavior to Steve.
• Added property to move behavior which allows for specification of alternate sequence, such as Targ using a charge animation.
