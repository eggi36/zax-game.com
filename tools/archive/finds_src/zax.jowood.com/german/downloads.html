DOWNLOADS

DEMO
Lade dir das Demo des Spiels herunter und erlebe das ultimative Abenteuer.
Warnung: Die Dateigröße ist 52MB, somit dürfte das Herunterladen etwas Zeit in Anspruch nehmen.

KLICK HIER um den Download zu starten.


WALLPAPERS

Zum herunterladen auf einen PC :
Klick auf das Bild das Du als Hintergrundbild benutzen möchten. Klick danach mit der rechten Maustaste darauf und wähle eine Speicheroption aus der Menüleiste.

Zum herunterladen auf einen Mac :
Klick auf das Bild das Du als Bildschirm-Hintergrund verwenden möchtest. Klick danach auf das neue Bild und halte die Maustaste gedrückt, um das Bild auf Deinen Desktop zu ziehen (oder alternativ auf dem Desktop speichern).
